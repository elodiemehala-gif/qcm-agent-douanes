# Frises chronologiques — histoire

Une frise verticale est associée à chacun des dix chapitres de la banque d’histoire.

Les dates et événements proviennent du cours validé. L’échelle est volontairement non proportionnelle : l’objectif est de mémoriser l’ordre des événements, pas de représenter graphiquement la durée exacte qui les sépare.

Dans l’application, la frise est accessible après la réponse dans un volet repliable. Elle ne peut donc pas révéler la bonne réponse avant la validation du QCM.
