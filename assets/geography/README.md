Principe d’intégration :
- le visuel apparaît uniquement après la validation de la réponse afin de ne pas révéler la solution ;
- le même visuel est réutilisé pour les questions d’un même ensemble ;
- les SVG sont embarqués localement afin de rester nets et accessibles hors connexion.

Le fond cartographique est issu de Natural Earth (domaine public), via le jeu de données mondial utilisé par D3 Graph Gallery.
